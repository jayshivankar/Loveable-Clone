# Colorful Todo App

Welcome to the Colorful Todo App! This application allows users to manage their tasks efficiently with a colorful and user-friendly interface. Below you will find instructions on how to set up the project, how to use it, and additional information for developers.

## Overview
The Colorful Todo App is designed to help users keep track of their tasks. Users can add, complete, and delete todo items. The app stores todos in the browser's local storage, ensuring that your tasks are saved even after refreshing the page.

## Installation
To set up the Colorful Todo App on your local machine, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/colorful-todo-app.git
   cd colorful-todo-app
   ```

2. **Open the `index.html` file** in your preferred web browser. The app does not require any additional dependencies or build steps, as it runs entirely in the browser.

## Usage
Once the app is open in your browser, you can start using it immediately:

1. **Add a Todo**: Type your task in the input field and press Enter or click the Add button. Ensure that the input is not empty.
2. **Complete a Todo**: Click on a todo item to mark it as completed. Completed items will be displayed with a strikethrough.
3. **Delete a Todo**: Click the Delete button next to a todo item to remove it from the list.
4. **Filter Todos**: You can filter the todos by completed and active states using the provided filter options.

## Troubleshooting
- **Todos not saving**: Ensure that your browser allows local storage. If local storage is disabled, the app will not be able to save your todos.
- **App not loading**: Make sure you are opening the `index.html` file directly in a web browser. If you are using a server, ensure it is configured correctly.
